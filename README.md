\# PORTIFOLIO



\## 📌 Sobre o Projeto



O \*\*PORTIFOLIO\*\* é uma aplicação web responsiva desenvolvida para apresentar o perfil profissional de uma Analista de Sistemas de forma moderna, elegante e minimalista.



O projeto utiliza apenas tecnologias front-end puras (\*\*HTML, CSS e JavaScript\*\*) e possui uma interface dinâmica com:

\- renderização automática de habilidades e contatos;

\- efeitos visuais modernos;

\- animações suaves;

\- design responsivo;

\- integração com links externos.



A aplicação foi construída com foco em performance, simplicidade e experiência visual.



\---



\## 🚀 Demonstração



O projeto exibe:

\- perfil profissional;

\- habilidades técnicas;

\- informações de contato;

\- links externos (LinkedIn, GitHub e e-mail);

\- efeitos de iluminação e paralaxe.
